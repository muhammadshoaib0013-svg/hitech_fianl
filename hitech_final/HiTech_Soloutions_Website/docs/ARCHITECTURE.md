# Architecture and design decisions

Design: cream/white foundation, midnight navy text and editorial dark sections, cyan action accents, Manrope/Inter typography, big product imagery, restrained motion. Primary funnel: attention → recognizable problem → example solution → product details → cart → (blocked until configured) secure provider checkout.

Current technology: dependency-free multi-page HTML, CSS and JavaScript. Rationale: offline preview and immediate portability without package installation. Existing user-approved HiTech campaign renders provide concept media.

Shared layout is generated by `generate.py`; `styles.css` maintains global responsive design tokens; `site.config.js` centralizes business values and unverified statuses; `site.js` manages UI/cart without pretending to implement commerce backend.

Status: visual storefront PREVIEW; production commerce integration OPEN/BLOCKED by real model, supplier details, price, contact, shipping, policies and account access. This must not be described as a working ecommerce checkout.
